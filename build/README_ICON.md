# Icon Placeholder

The `build/icon.ico` file should be a 256x256 pixel Windows icon file (.ico format).

To create one:

1. Design a logo for ScaleHouse Connector
2. Convert to .ico format using online tools like:
   - https://convertio.co/png-ico/
   - https://www.icoconverter.com/
3. Place the file at `build/icon.ico`

For now, a placeholder is needed to build the MSI.
